ID инцидента: INC-DQ-2026-042
Время срабатывания: 04.09.2026 03:15 (ночной пайплайн).
Алерты: Soda Check missing_percent(email) показал 15% пропусков (норма < 1%).
Расследование:
Изучены логи Airflow — таск упал с ошибкой чтения файла.
Выгрузка из CRM-системы пришла в кодировке Windows-1251 вместо UTF-8.
Парсер прочитал колонку email как бинарные данные, интерпретировав их как пустые.
Root Cause: Отсутствие строгого контракта на стороне источника (CRM-отдела), смена провайдера выгрузок без уведомления шины данных.
Corrective Actions:
Краткосрочная: Ручной перезапуск задачи после конвертации файла.
Долгосрочная: Добавить проверку кодировки (chardet) первым шагом в пайплайн; провести встречу со смежной командой и зафиксировать формат обмена в Data Contract.
