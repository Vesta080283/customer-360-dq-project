Проект: Data Quality в домене Customer 360

Этот репозиторий содержит полный цикл работы Data Quality-специалиста по датасету «Customer 360» от vinaykandimalla (Kaggle). В проекте реализованы все этапы: от анализа сырых данных до создания работающего пайплайна с автоматическими алертами.

Описание проекта

В рамках курса вы закрепили навыки построения систем контроля качества. Вы прошли путь от выявления проблемных мест в "грязном" наборе данных до разработки стратегии внедрения DQ-процессов в компании.

Цель: Показать ценность качественной информации через создание портфолио-кейса.

Бизнес-домен: E-commerce / SaaS

Компания хочет построить единый профиль клиента (Customer 360) для персонализации маркетинга и предотвращения оттока. Для этого она собирает данные из разных источников:

CRM: информация о пользователях (crm_50000_customers_dirty_v3.csv).
Clickstream/Orders: логи поведения пользователей и покупки (orders_300k_dirty.csv).
Каталог товаров: прайс-лист со случайными ошибками (product_catalog_dirty_30pct.csv).
Поддержка: обращения клиентов (support_tickets_30000_dirty.csv).

Риски плохого качества:

Дубликаты email → неверная сегментация аудитории.
Пропуски в идентификаторах заказов → поломанные аналитические дашборды.
Отрицательные суммы покупок → искажение LTV и выручки.
Неактуальные тикеты поддержки → нарушение SLA.
